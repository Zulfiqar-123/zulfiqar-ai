# Zulfiqar AI – Personal AI Chatbot

Zulfiqar AI is a personal AI chatbot built using Node.js, Express.js, and the Groq API.

## Features

- AI-powered chat responses
- English and Roman Urdu text conversations
- Voice input using audio transcription (experimental)
- AI voice replies
- Simple and user-friendly chat interface

## Technologies Used

- HTML
- CSS
- JavaScript
- Node.js
- Express.js
- Groq API
- Whisper audio transcription

## Installation

1. Clone or download this repository.
2. Open the project folder in your terminal.
3. Install dependencies:

   `npm install`

4. Create a `.env` file in the project folder:

   ```env
   GROQ_API_KEY=your_groq_api_key
   GROQ_MODEL=openai/gpt-oss-120b
   PORT=3001
   ```

5. Start the development server:

   `npm run dev`

6. Open your browser:

   `http://localhost:3001`

## Security

Never upload your real API key or `.env` file to GitHub.
